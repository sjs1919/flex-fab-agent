> **日期**：2026-08-22
> **作用**：demo 第二阶段重构的技术栈基准清单；前端（web/index.html G5、可观测 Dashboard B8）涉及 UI 时，一律引入 `token-hub/web-portal` 的框架与风格（用户 2026-08-22 指定）。
> **关联**：[重构方案 v1](重构方案-v1-2026-08-21.md) · [排程排产需求规格 v1](排程排产需求规格-v1-2026-08-21.md)

## 1. 后端与数据（现状 + Phase 2）

| 层 | 选型 | 说明 |
|----|------|------|
| 语言 | Python **3.11 锁定** | 依赖只改 `requirements-demo.txt`，不随意升级 |
| Agent 编排 | LangGraph | 单 Agent + Supervisor 多 Agent 双模式 |
| API | FastAPI（`api.py`） | 只读看板端点 `GET /schedule/latest` 等 |
| 求解器 | OR-Tools CP-SAT | 预算内返回次优可行解（蓝图 R-D1） |
| 事务库 | MySQL | **跑 WSL**，Windows 只经 localhost 访问 |
| 向量库 | Chroma | **跑 WSL**，同上 |
| 迁移/种子 | 脚本化 down/up + `simulator/seed.py` | 禁止手改库 |
| 测试 | pytest（`run_all_tests.py`） | mock LLM 零成本；eval 基线 >=7/10 |

## 2. 基础设施

- **数据库服务（MySQL / PostgreSQL / Chroma）一律跑 WSL**；禁止 Windows 本机安装。
- **Docker / 前端 / 镜像构建必须在 WSL 下执行**（EPERM 文件锁教训）。
- compose 带健康检查；`/health` 报数据源与模拟器 tick 状态。

## 3. 前端规范（基准：token-hub/web-portal）

> 用户指定：**凡涉及前端，引入 `token-hub/web-portal` 的框架或风格**。以下为其技术栈全景，作为本项目前端唯一基准。

### 3.1 框架与依赖

| 类别 | 选型 | 版本 |
|------|------|------|
| 框架 | Vue 3（Composition API + `<script setup lang="ts">`） | ^3.4 |
| 语言 | TypeScript | ^5.4 |
| 构建 | Vite + @vitejs/plugin-vue | ^5.1 |
| UI 库 | Element Plus + @element-plus/icons-vue | ^2.6 |
| 路由 | vue-router（createWebHistory） | ^4.3 |
| 状态 | Pinia | ^2.1 |
| HTTP | axios（经 api-client 包封装） | ^1.6 |
| 图表 | echarts | ^5.5 |
| 单测 | Vitest + @vue/test-utils + jsdom | ^2.0 |
| E2E | Playwright | ^1.44 |
| 类型检查 | vue-tsc（`build` 前置 `--noEmit`） | ^2.0 |

### 3.2 目录结构模式

```
src/
├── components/    # 布局组件：AppLayout / AuthLayout / AppHeader / AppFooter
├── views/
│   ├── public/    # 公开页（Home / Login / Register...）
│   └── app/       # 登录后应用页（Dashboard / Model / Trace...）
├── composables/   # useAuth 等逻辑复用（带 .test.ts）
├── stores/        # Pinia store（user 等，带 .test.ts）
├── router/        # 路由 + meta.requiresAuth 守卫（带 .test.ts）
├── styles/        # variables.css（主题变量）+ global.css（reset）
├── utils/         # 纯函数工具
└── main.ts
```

### 3.3 风格规范（styles）

- **主题变量**（`variables.css`，SoybeanAdmin 绿色主题）：

```css
:root {
  --el-color-primary: #18a058;        /* 及 light-3/5/7/8/9、dark-2 梯度 */
  --el-color-success: #18a058;
  --el-color-warning: #f0a020;
  --el-color-danger: #d03050;
  --header-height: 56px;
  --content-max-width: 1200px;
}
```

- **全局 reset**（`global.css`）：box-sizing: border-box；系统字体栈；背景 `#f5f7fa`；链接去下划线。
- **路由模式**：布局组件包裹子路由（AppLayout=顶栏+底栏，AuthLayout=Logo+返回）；`meta: { requiresAuth: true }` + Pinia user store 守卫。

### 3.4 应用到 demo（已确认：方案 A）

> **2026-08-22 用户确认方案 A**：前端升级为完整 Vue3 栈。理由：demo 前端不会只有两个静态页，后续将增加更多页面（配置信息页等）并要求动效。

| 项 | 方案（A） |
|----|----------|
| 前端形态 | `web/` 目录下 Vue3 + Vite + TS + Element Plus 单应用（结构照搬 §3.2） |
| G5 主页/调试台 | Vue 视图：输入框 -> 执行链路可视化 -> judge 打分 -> 人工标注 |
| B8 可观测 Dashboard | Vue 视图 + ECharts，消费只读 API（KPI 曲线/成本分模型/trace 摘要）；`dashboard.py` 静态 HTML 生成降为离线报告兜底 |
| 配置信息页 ⭐ 新增（用户 2026-08-22 提出） | Vue 视图：展示/编辑运行配置（数据源切换、模拟器时钟速率、求解器预算等，读写走 API） |
| 动效 ⭐ 新增（用户 2026-08-22 提出） | Element Plus 内置过渡 + 自定义动画（路由切换、数据加载、链路树展开） |
| 构建 | 全部在 WSL 下执行；`vue-tsc --noEmit` 前置于 build |

> 新增页面与动效属于**演进范围**（M5 之后按需排期），G5/B8 的 Vue 化随第二阶段重构落地。

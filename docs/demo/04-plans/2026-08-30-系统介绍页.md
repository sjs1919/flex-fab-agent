# 系统介绍页（首页 tab）实现计划

> **面向 AI 代理的工作者：** 必需子技能：使用 superpowers:subagent-driven-development（推荐）或 superpowers:executing-plans 逐任务实现此计划。步骤使用复选框（`- [ ]`）语法来跟踪进度。
> **规格**：`docs/demo/02-specs/2026-08-30-系统介绍页-design.md`
> **⚠️ Commit 红线**：本计划所有 commit 步骤仅给出命令，**实际提交必须经用户批准后由用户发起**（项目红线：禁止自动 git）。

**目标：** 新增「首页」tab（`OverviewView.vue`）作为 Web 控制台 `PortalView` 的第一个 tab 和登录后的默认首页，纯静态、零 API 依赖，面向业务方通俗介绍系统功能 / 业务架构 / 技术架构 / 测试示例。

**架构：** `OverviewView.vue` 为自包含静态组件——全部文案与数字内联在组件中，不 import 任何 `api/*`，后端未启动也能完整渲染。图表用 CSS（大数字卡、卡片、条形、时间线）与内联 SVG（流程箭头），**不引入 ECharts**（规避 `PortalView.onTabChange` 仅为 dashboard 做 `resizeCharts` 的问题）。组件通过 `emit('switch-tab', name)` 请求 `PortalView` 切换 tab；`PortalView` 把 `activeTab` 默认值改为 `'overview'`，并插入第一个 `el-tab-pane` 监听该事件。

**技术栈：** Vue3 `<script setup lang="ts">` + Element Plus + Vite + vue-tsc（`npm run build` = `vue-tsc --noEmit && vite build`，构建即含类型检查）。前端无测试框架（web/package.json 无 vitest/jest），规格 §8 未要求单元测试，验证以构建 + 类型检查 + 手动/脚本 E2E 为准。

| 文件 | 操作 | 职责 |
|------|------|------|
| `web/src/views/OverviewView.vue` | **创建** | 介绍页组件：7 区块内容 + 静态数据数组 + `switch-tab` emit |

不改 `router`、`App.vue`、其余 6 个 View（规格 §6.3：不新增路由、不加深链、不改鉴权）。

- [ ] **步骤 2：写 template——Hero 区块（①）+ 痛点（②）**

  Hero：`.overview` 根容器（`padding: 24px; max-width: 1200px; margin: 0 auto`），主标题「面向 3D 打印柔性制造的智能排产系统」、副标题定位语（规格 §5.1），下接 4 个大数字卡（`v-for="s in heroStats"`，`.stat-value` 用 `font-size: 40px; font-weight: 700` 强调）。痛点：`el-card shadow="never"` 三列（`el-row :gutter` / flex），每卡 icon + title + desc。

- [ ] **步骤 3：写 template——业务闭环（③，核心区）**

  6 步横向流程：CSS flex 一行卡片 + 箭头（`→` 字符或内联 SVG），每卡三步信息（step 名 / who 标签 / desc）。窄屏自然换行（`flex-wrap`）。此区块是业务核心，务必放在痛点之后、能力速览之前。

- [ ] **步骤 4：写 template——能力速览（④）+ 可靠性（⑤）**

  能力：4 张 `el-card`，含能力名 + desc + `el-input`（只读显示提问示例，带 copy 按钮或直接可选中文本）+「去试试」`el-button`（`@click="emit('switch-tab', a.tab)"`）。可靠性：3 个数字格 + `el-collapse` 折叠面板「现场 15 分钟演示」，展开显示 `demoLine` 主线（每项对应一句提问，指向调试台测试用例 v1 文档）。

- [ ] **步骤 5：写 template——技术架构（⑥）+ 从哪开始（⑦）**

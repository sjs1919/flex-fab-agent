# 排产控制台单页 Tab 聚合 实现计划

> **日期**：2026-08-26 · **状态**：已批准，实施中

## Context

前端当前 5 个页面分散在顶部菜单（排产看板 / 调试台 / 案例台 / 配置）+ 一个**无菜单入口**的排产审批页（`/portal/schedule`，有路由但 App.vue 菜单未加）。用户需在页面间来回切换，且审批入口缺失。

**目标**：把所有已实现页面聚合到一个 tag 切换页面，消除分散查找，补齐审批入口。

**用户已确认**：
- 聚合范围：**全部已实现页面**通过 tab 集成（看板 / 调试 / 审批 / 案例 / 配置）
- 顶部导航：**去掉 el-menu**，单页 tab 为主
- 独立路由 `/portal/schedule` 保留作深链

## 方案

新建 `PortalView.vue` 聚合容器（element-plus `el-tabs`，5 个 tab，`lazy` 首激活渲染），嵌入现有 5 个视图组件；`/` 路由指向聚合页；App.vue 去掉顶部菜单；保留 `/portal/*` 深链路由。

## 改动文件

| 文件 | 动作 | 内容 |
|------|------|------|
| `web/src/views/PortalView.vue` | 新建 | `el-tabs`（`lazy`）5 tab：看板/调试/审批/案例/配置，嵌入 5 视图；`@tab-change` 切回看板时 `nextTick` 调 `dashboardRef.resizeCharts()` |
| `web/src/router/index.ts` | 修改 | `/` → `PortalView`（默认 tab=看板）；保留 `/portal/debug\|cases\|config\|schedule` 深链 |
| `web/src/App.vue` | 修改 | 删除 `el-menu` 顶部导航，仅保留 `<router-view>` + fade 过渡 |
| `web/src/views/ScheduleView.vue` | 修改 | token key `admin_token` → `debug_admin_token`（与其他页统一）；`onMounted` 自动签发 `fetchAdminToken()`（对齐 DebugView） |
| `web/src/views/DashboardView.vue` | 修改 | `handleResize` → `resizeCharts` + `defineExpose`，供聚合页切换回看板时重算 echarts 尺寸 |

## 验证

2. 容器已挂载 `./web/dist`，build 后 FastAPI 同源托管新前端，无需重 build 镜像
3. 浏览器 `http://localhost:8000/`：
   - 5 个 tab 全部可见，切换正常、无控制台报错
   - 看板 tab：KPI/成本/trace 图表正常渲染（非 0 尺寸）

   - 审批 tab：版本列表加载，token 已自动签发，点「通过」状态刷新为已审核
   - 案例/配置 tab：列表与开关正常
4. 深链：`http://localhost:8000/portal/schedule` 等 4 条仍返回页面（200）

## 4. 追赶路线（如何把 demo 追上）

> 原则：**重构方案 M1-M5 为主菜**（排产核心+模拟器+求解器+审批+预测闭环）；B 组为"求职冲刺补强"，按 **面试说服力 ÷ 实现成本** 排序，逐项落地到重构方案，不另起炉灶。

### 阶段 A：重构方案 M1-M5（已在案，不重复）
排产核心 / MySQL / 模拟器 / 求解器 / 审批 / RBAC / 预测闭环（§6.4）→ 已完成文档落盘。

### 阶段 B：冲刺补强（M5 后追加，建议全部进重构方案 §7.7）

| 优先级 | 追赶项 | 补法 | 成本 | 面试价值 |
|:---:|--------|------|:---:|---------|
| **B1** | 在线复盘看板 | `query_kpi` 工具 + `GET /kpi`：从 DB 实时算**准交率 / 延期金额(Σ金额×费率×天数) / 舱利用率 / 良率 / 前道瓶颈占用**，随时间曲线（模拟器驱动天然有故事） | 低 | **高**（3 家 JD 点名"量化复盘/质量评分/监控回归"） |
| **B2** | 库存补货 | `query_material_status` + `suggest_replenish`：消耗速率→耗尽点 vs 采购周期→建议补货量 | 低 | 中（"供应链计划闭环"） |
| **B3** | 模型路由 | `llm_client` 按任务路由（简单查询→快/便宜模型、排产/复杂→强模型），token-hub 路由逻辑内嵌 | 低-中 | **高**（安克/绿联点名"成本优化"） |
| **B4** | RAG 权限检索 | 检索时按角色过滤知识文档（保密合同），接 RBAC + tenant | 低-中 | 中（安全合规，合元"合规风控"） |
| **B5** | 工具沙箱 | ✅ **已入案**：**轻量工具治理**（registry.execute 只读/写标记校验，写工具带 token+权限缺省拒绝，并入现有 RBAC；不做进程隔离——demo 工具全为内部函数） | 低 | 中（绿联"沙箱"） |
| **B6** | Prompt/工作流版本化 | ✅ **已入案**：prompt 配置化带版本号（system_config）+ `--rollback` 回滚 + graph 版本入版本表（复用 schedule_versions 或新增 prompt_versions）；轻量版本化，不做灰度发布 | 中 | 中（安克/绿联"版本管理/回滚"） |
| **B7** | 良率闭环 | ✅ **已入案**：query_yield 良率下钻（设备/批次/材料）+ bad_parts 根因归因 + LLM 改善建议 | 低-中 | 中（合元"良率优化"） |
| **B8** | 可观测 Dashboard | ✅ **已入案**：observability/dashboard.py 生成 dashboard.html（KPI 曲线+成本统计+trace 摘要），M5 落地 | 中 | 中（可视化演示力） |

**推荐取舍**：B1+B3 必做（说服力最高、成本可控）；B2+B4 顺带（供应链闭环 + 合规）；B5/B6/B7/B8 按时间择取，面试时至少能讲设计。

## 5. 面试口径落地（配合追赶项）

- **主菜话术**："供应链计划 = 预测 + 排产，demo 用轻量时序补齐预测，形成完整闭环（不训练模型，管理侧分工）"
- **量化话术**："评估不只在离线，线上每 tick 的效果量化（准交率/延期金额/良率）才是复盘依据"（B1）
- **成本话术**："模型路由按任务分模型，月度成本可控"（B3，token-hub 背书）
- **治理话术**："工具执行带沙箱隔离，知识检索带权限，工作流可发布可回滚"（B4/B5/B6）

# M5a 会话踩坑迁移（2026-08-24）

> 按 `rules/common/pitfalls.md` 从 job-portfolio/sessions/session-2026-08-24-M5a后端能力完成.md 迁移 + 本轮新增。每项独立成节，复用同一文件格式。

## 1. Windows 默认数据源 csv（手动验收必需 DEMO_DATA_SOURCE=mysql）

- **根因**：config.py 默认 `DEMO_DATA_SOURCE=csv`（遗留兜底），csv 模式 machines.csv 无 `id`/`cabin_size` 键，`query_kpi` 抛 KeyError 'id'。
- **教训**：手动验收/脚本跑 demo 必须 `DEMO_DATA_SOURCE=mysql`；csv 是历史兜底路径不是正式数据源。
- **规避**：测试用 mysql_source fixture；文档明确命令前缀。
- **升级为规则**：否（一次性环境约定，已固化进验收文档）。

## 2. 后台回归运行期间 DB 瞬时状态（query_forecast 首查空）

- **根因**：与后台回归并发时 DB 有瞬时写入中状态，首个查询返回空。
- **教训**：勿把并发环境下的瞬时结果误判为 bug；复查一次确认。
- **规避**：先查「当前是否有并发回归/种子写入」，再下结论。
- **升级为规则**：否。

## 3. eval runner multi 分支 lazy import（monkeypatch 须 patch 源模块）

- **根因**：runner 在 multi 分支内 `from ..agents.supervisor import run_supervisor`（lazy），patch runner 上的名字无效。
- **教训**：lazy import 的 monkeypatch 必须 patch 源模块 `demo.agents.supervisor.run_supervisor`，不是 runner 层的名字。
- **规避**：测试里 `monkeypatch.setattr(supervisor_mod, "run_supervisor", fake)`。
- **升级为规则**：否（测试写法约定）。

## 4. ragas/脚本直接跑注意 Windows GBK 控制台

- **根因**：Windows 默认 GBK 控制台，脚本直接跑时 emoji/中文打印可能报编码错。
- **教训**：直接跑脚本用 `python -X utf8`；run_all_tests.py 内部已重配 stream。
- **规避**：CLI 手动跑一律 `python -X utf8`。
- **升级为规则**：否。

## 5. pytest 单进程共享 env：测试改 os.environ 不还原会污染其他测试（本轮新增）

- **根因**：`test_run_eval_disables_semantic_cache` 里 `os.environ["SEMANTIC_CACHE"]="off"` 没还原 → 全量回归中后跑的 `test_is_semantic_enabled_default` 读到 off → assert False（386 passed + 1 failed）。
- **教训**：任何测试直接改 os.environ 必须在 finally 还原原值（monkeypatch.setenv 无效——被测代码用 `os.environ[...]=` 覆盖它）；单进程 pytest 全量共享 env，跨文件污染最隐蔽。
- **规避**：save 原值 → try/finally 还原。
- **升级为规则**：否（首次出现；若再发生 env 泄漏污染测试 → 升级 rules/common/「测试不得泄漏环境变量」）。

## 6. 真实 LLM 回归遇 429 限流（本轮新增）

- **根因**：火山豆包 AccountQuotaExceeded 429，多次 LLM 调用失败。
- **教训**：主备切换 + `_llm_json` 重试兜住了大部分；answer 生成成功、judge 失败返回 {} 时该项判 0——结果仍可信（本次四指标全达标）。
- **规避**：大回归避开高峰；失败会打印「切下一个」说明主备切换生效。
- **升级为规则**：否。

## 7. 后台任务输出管道缓冲（本轮确认）

- **根因**：`python ... | tail -N` 中 tail 缓冲到进程结束才输出，看不到实时进度。
- **教训**：后台命令重定向到文件（`> /tmp/x.log 2>&1`）再 tail 文件，才能实时查看。
- **规避**：后台长任务一律重定向日志文件。
- **升级为规则**：否（工作方法）。

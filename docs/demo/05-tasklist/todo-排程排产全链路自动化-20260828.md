## 拆分依据

- **规格已过 3 轮 9 角色审批**（每轮 9 条 must_fix 全部落实）+ 用户拍板（u-d-1 启用 / u-d-2 不启用 / topN=5），本 todo 仅为 §5 改动点表的**机械拆分**，不引入新设计决策，不再重复跑 9 角色 workflow。
- **自底向上**：先地基（config/seed）→ 求解输入（model/snapshot）→ persist 核心 → 读路径 → 审批/推进 → 集成验收。
- **Phase 门禁**（workflow.md）：每 Phase 结束 `python -m compileall demo` + 相关测试全绿 + 回核 spec §6 该 Phase 覆盖的验收条目。
- **测试前置/清理约定**（spec §6 文末注）：persist 相关 fixture `seed.reset` 后补 `init_clock(T0)`；清理顺序先 `DELETE preprocess_tasks`→`batches`→`schedule_versions` + 还原 `orders.status`；新单测手工造单号须先 INSERT 待排队订单；并发双 persist 用「顺序连调两次」确定性写法。

## 建模方案（demo 规模两段式）

**设计决策（简单优先 + 秒级可解）**：CP-SAT 全量建模（part→batch→machine→time 单模型）在 348 part × 7 台规模下变量爆炸。采用**两段式**：

- **Step 1 · 贪心装箱（model.py）**：确定性分组，非 CP 变量。
  - 按材料→机型分组（C1 同舱同材料 / C3 机型匹配）；part 排序键 = 交期升序 → priority 降序（v1 §6.2 排序键）
  - 容量判定 C2：`max(长,宽,高) ≤ cabin_size`（包络盒允许旋转）+ `Σ投影面积×0.7 ≤ cabin_size²` + 件数 ≤ part_limit + `Σ件重 ≤ max_weight`（part_limit/weight_limit 读 system_config，缺省默认 50/600）
  - 整批优先、超舱可拆（C5）：同订单 part 尽量同批；超容量拆新批，`source='拆批'` 记录
  - 超尺寸 part（某边 >600）**不静默**：入预警清单，不参与排产（验收 3 条）
- **Step 2 · CP-SAT 排程（model.py）**：批次 → 设备 + 时间槽。
  - 决策变量：batch→machine 指派（布尔，仅工艺/机型匹配）、每 batch interval（start/end 整数小时）
  - 时长 C4：batch 时长 = `max(单件时长)`，单件时长 = `max(长,宽,高)/rate_mm_h` + `post_process_hours` 静置；**interval 含静置**（C6 静置占用设备，保守建模）
  - 约束：C6 同机 interval no_overlap（设备互斥）；C7 `end ≤ due_date 当天 23:59` 且延期以天计；C8 每设备日可用 = 24h×(1−emergency_reserve) = 21.6h（reserve 默认 0.10，应急池预留）；C9 前道空 → 无前道变量（恒真）
  - 目标：主 = `min Σ(订单金额 × penalty_rate × 延期天数)`（线性：金额×费率常量 × 延期天数变量）；软惩罚 = 同订单拆入不同 batch 的 part 数；次 = 舱利用率（产能宽松时）
  - 预算：`solver.max_time_in_seconds = solver_max_time_seconds`（默认 60）；超时返回当前最优可行解 + `timed_out=true` + 耗时；无可行解 → 冲突订单清单（含超尺寸预警）

**输出**：`schedule_versions`（result_json 全表 + params_json）+ `batches` 行（order_ids JSON / parts_json / process / model_type / machine_id / start_time / end_time / post_process_end / status='前道' / approval_status='待审核' / source）+ 指标（准交率/舱利用率/延期清单/超尺寸预警清单）→ solver.py 单事务写入。
